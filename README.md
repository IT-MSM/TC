# Trust Center — المنصورة

موقع عربي ثابت لمركز تنسيق وطباعة الرسائل العلمية والماجستير والدكتوراه. الملفات المطلوبة للتشغيل: `index.html`, `settings.html`, `style.css`, `app.js`, `settings.js`, و`qrcode.js`.

## رفعه على GitHub Pages

1. فك ضغط ملف `trust-center-github.zip`.
2. ارفع كل الملفات والمجلدات الموجودة داخله إلى جذر مستودع GitHub.
3. من إعدادات المستودع افتح **Pages**، واختر **Deploy from a branch**، وحدد الفرع `main` ومجلد `/ (root)`، ثم احفظ.
4. افتح رابط GitHub Pages الذي يظهر في إعدادات المستودع.

تقدر تختبر الموقع محليًا بفتح `index.html` في المتصفح. بعض وظائف الهاتف مثل `tel:` وفتح التطبيقات تختلف حسب الجهاز والمتصفح.

## الإعدادات وتغيير الأرقام

صفحة الإعدادات غير ظاهرة في القائمة. اكتب `0000` على لوحة المفاتيح أو اضغط `0000` الصغير بأسفل الموقع، ثم استخدم رمز الدخول `0000`. التغييرات تُحفظ في `localStorage` على نفس المتصفح فقط؛ الموقع الثابت لا يقدر يغيّر ملفات GitHub أو يزامن التعديل مع أجهزة الزوار. لتعميم رقم أو كلمة مرور جديدة، عدّل القيم في بداية `app.js` وارفع الملفات من جديد. رمز 0000 حاجز بسيط داخل المتصفح وليس نظام حماية.

## Vodafone Cash

اكتب المبلغ ثم اختار Vodafone Cash. الموقع يكوّن طلب اتصال على `*9*7*رقم المستلم*المبلغ#` ويفتح شاشة الاتصال. لازم تستخدم شريحة Vodafone وتضغط اتصال بنفسك؛ بعد ذلك راجع تفاصيل التحويل وأكّده من الهاتف. الموقع لا ينفذ التحويل ولا يطلب الرقم السري. المبلغ يقبل أعدادًا صحيحة من 5 إلى 60,000 جنيه. هذه صيغة الخدمة كما توضحها [صفحة Vodafone Egypt الرسمية](https://web.vodafone.com.eg/ar/money-transfer).

## InstaPay

تطبيق InstaPay يستقبل التحويل برقم الهاتف المسجل أو IPA، لكن رابط الدفع المباشر المعروض للمرسل يعتمد على رابط/عنوان يخص المستلم. زر الصفحة ينسخ رقم الفترة ويفتح صفحة InstaPay العامة؛ إذا كان للمركز رابط دفع مباشر، افتح الإعدادات وأضفه في حقل رابط InstaPay المناسب كي يفتح هذا الرابط بدل الصفحة العامة. الموقع لا يؤكد التحويل؛ راجع المستلم والمبلغ داخل التطبيق. راجع [موقع InstaPay الرسمي](https://www.instapay.eg/?lang=ar).

## Wi-Fi

زر الشبكة يعرض رمز QR مشفرًا ببيانات اتصال `C.T`. المتصفح لا يملك صلاحية وصل الجهاز تلقائيًا بشبكة Wi-Fi، لذلك يحتاج الزائر إلى مسح الرمز والموافقة على الاتصال أو استخدام إعدادات الجهاز. كلمة السر لا تظهر كنص في الصفحة، لكنها جزء من كود QR ومن إعدادات JavaScript؛ أي شخص يستطيع فحص ملفات موقع منشور يقدر يستخرجها. لا تستخدم كلمة مرور خاصة أو حساسة لشبكة عامة.

## ملاحظات

- واتساب وتليجرام يفتحان محادثة؛ على الزائر اختيار ملفه وإرفاقه يدويًا.
- رابط الخريطة يبحث عن العنوان النصي في Google Maps؛ راجع نتيجة الموقع قبل الطباعة النهائية.
- الأيقونات مرسومة داخل HTML، ورمز QR يعمل بكود محلي مرفق (`qrcode.js`). لا يحتاج الموقع خادمًا أو قاعدة بيانات.
